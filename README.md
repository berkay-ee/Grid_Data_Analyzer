# EPIAS Data Extractor and Categorizer

## Purpose
This system extracts Turkish electricity market data from EPİAŞ (Energy Exchange Istanbul) and exports it into Excel format. Its primary function is to process the raw data and categorize it based on subscriber types, electricity consumption levels, and related electrical properties.

## Requirements
- Python 3.8+
- Required libraries listed in `requirements.txt`
- EPİAŞ platform access/credentials
